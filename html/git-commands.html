Common git-commands

Here are some common everyday git-commands!

git init

Initializes a brand-new local Git repository in your current folder.

git clone

Downloads an existing copy of a repository from a remote server (like GitHub).

git status

Shows the current state of your working directory (tracked, untracked, or modified files).

git add

Stages file changes, preparing them to be included in your next snapshot.

git commit

Saves your staged snapshot securely to the project history with a descriptive message.

git log

Displays a chronological list of all previous commits in the project history.

git branch

Lists, creates, or manages isolated contexts/versions of your project.

git checkout

Switches your working environment to a different branch.

git merge

Combines the history and changes of another branch into your active branch.

git push

Uploads your local commits to a remote reposity server so collaboratos can access them.

Your project starts with git init or git clone.

git status shows what changed, git add stages it, and git commit saves a snapshot.

git log shows past commits.

git branch and git checkout let you work on separate versions(branches), then git merge combines them.

git push sends commits to a GitHub. A new GitHub repo starts with one default branch, usually main.
