About github projects

Github projects let you organize and prioritize your work in a visual way.

A project is an adaptable board that integrates issues and pullrequests on GitHub to help with planning and tracking work in a effective and efficient manner, for both at the user and/or organization level. It's never been easier to create and customize multiple views by filtering, sorting, slicing, and grouping issues and pull requests to manage team backlogs and roadmaps, visualize work with configurable charts, add custom fields to track metadata specific to the team, create templates, share status updates, and automate projects. Rather than enforcing a specific methodology, a project provides flexible features that can customize to the team’s needs and processes.
